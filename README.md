# Allow 자동 클릭기

화면에서 지정한 영역만 지켜보다가 보라색 `Allow` 같은 버튼이 뜨면 자동으로 눌러준다.
Windows와 macOS에서 같은 코드로 돌아간다. OS마다 다른 처리는 `allowclicker/platforms/`
안에만 들어 있다.

## 준비

Python 3.10 이상과 tkinter가 필요하다. 나머지 의존성은 `mss`, `numpy` 두 개뿐이다.
Windows 공식 설치본에는 tkinter가 들어 있다. macOS는 아래 macOS 항목을 먼저 보면 된다.

## 실행

두 OS의 명령이 같다. 실행 파일 이름만 Windows는 `python`, macOS는 `python3`이다.

```bash
python -m pip install -r requirements.txt      # macOS: python3 -m pip ...
python run.py                                  # macOS: python3 run.py
```

가상환경을 쓸 거면 활성화 명령만 다르다.

```bash
python -m venv .venv                           # macOS: python3 -m venv .venv
.venv\Scripts\Activate.ps1                     # macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
python run.py
```

`python -m allowclicker`로 실행해도 똑같다.

## 처음 쓸 때

1. 맨 위에서 버튼이 있는 모니터를 고른다. 나중에 해상도나 모니터 배치를 바꿨으면
   `새로고침`을 누른다.
2. `버튼 영역 지정`을 누르고 눌러야 하는 버튼을 드래그로 감싼다. 테두리에 딱 맞게
   잡을수록 정확하다. 이때 그 버튼의 색과 크기, 모양을 재서 인식 기준으로 삼고
   감시 영역도 버튼 주변으로 잡아준다.
3. `한 번 검사`를 눌러 미리보기를 확인한다. 초록 사각형이 실제 버튼에 씌워져 있으면 된다.
4. `시작`을 누른다. 감시 중에는 F8로 언제든 멈출 수 있다.

버튼 영역을 지정하지 않고 감시 영역만 잡아도 된다. 그러면 시작할 때 영역 안에서
버튼처럼 생긴 것을 스스로 찾아 기준을 학습한다. 시작 시점에 버튼이 없으면 나타날 때까지
기다렸다가 그때 학습한다.

버튼만 잘라낸 PNG나 GIF 파일이 있으면 `이미지로 지정`으로 등록해도 된다.

## 창 구성

**0. 모니터** — 감시할 모니터를 고른다. `이 모니터 전체 감시`는 그 모니터 전체를
감시 영역으로 잡는다.

**1. 감시 영역** — `영역 선택`으로 직접 드래그해서 잡을 수 있다. `한 번 검사`는 지금
화면을 한 번 찍어서 버튼을 찾아보고 결과를 로그와 미리보기에 보여준다.

**2. 버튼 인식 기준** — `버튼 영역 지정`, `이미지로 지정`, `견본 지우기`가 여기 있다.
`캘리브레이션`은 버튼을 직접 클릭해서 기준을 학습하는 방식이고, `기본값`은 기준과
클릭 보정값을 초기 상태로 되돌린다. 색상과 허용 범위, 견본 일치도 최소값은 직접 고칠 수도
있지만 보통 건드릴 필요가 없다.

**3. 동작 설정** — 검사 간격, 클릭 후 대기 시간, 연속 감지 횟수, 최대 클릭 횟수,
재시도 횟수(0이면 버튼이 사라질 때까지), 한 버튼에 매달리는 제한 시간을 정한다.
체크박스로 시작할 때 자동 캘리브레이션, 클릭 좌표 자동 보정, 테스트 모드,
클릭 전 대상 창 활성화, 클릭 후 커서 복귀, 창 항상 위를 켜고 끌 수 있다.
테스트 모드를 켜면 감지만 하고 실제로 누르지는 않는다.

**4. 고급** — 채도, 명도, 채움율, 크기 범위 같은 세부 조건이다. 캘리브레이션이
알아서 채우니 인식이 이상할 때만 손대면 된다.

아래쪽 미리보기는 감시 영역을 그대로 보여주고, 클릭 대상에 초록 사각형을 그린다.
로그에는 학습 결과, 클릭 좌표, 보정값, 실패 이유가 남는다.

## 동작 방식과 안전장치

같은 자리에서 여러 프레임 연속으로 감지돼야 클릭한다. 화면이 그려지는 중간에
잘못 누르는 걸 막기 위한 것이다.

누르기 전에 커서가 실제로 그 좌표에 도착했는지 확인한다. 어긋나 있으면 그 차이를
보정해서 다시 옮긴 다음에 누른다. 배율이나 좌표계가 어긋난 환경에서도 첫 클릭부터
제대로 들어가고, 학습한 보정값은 저장돼서 다음 실행에도 쓰인다.

눌렀는데 버튼이 그대로 남아 있으면 사라질 때까지 다시 누른다. 비활성 창의 첫 클릭이
창을 깨우는 데만 쓰이고 버려지는 경우가 있어서다. 다만 매번 버튼이 여전히 보이는지
확인한 뒤에만 누르고, 한 버튼에 매달리는 시간에 상한이 있다.

감시 중에 해상도나 모니터 배치가 바뀌면 저장된 좌표가 의미를 잃기 때문에 자동으로 멈춘다.

승인 버튼을 대신 누르는 도구다. 확인 없이 실행되면 안 되는 작업이 있을 수 있으니
감시 영역은 필요한 버튼 주변으로 좁게 잡는 게 안전하다.

## macOS

기본 `python3`에는 tkinter가 없을 수 있다. 없으면 `brew install python-tk`로 설치하거나
python.org 설치본을 쓴다.

권한 두 개를 허용해야 동작한다. 시스템 설정 → 개인정보 보호 및 보안에서 화면 기록과
손쉬운 사용을 켜준다. 화면 기록이 없으면 배경화면만 캡처돼서 버튼을 아예 못 찾고,
손쉬운 사용이 없으면 클릭이 조용히 무시된다. 둘 다 실패해도 오류가 안 나기 때문에,
프로그램이 시작할 때 권한 상태를 확인해서 로그에 경고를 남긴다.

터미널에서 실행하면 권한은 터미널에 부여된다. macOS 15부터는 화면 캡처 권한 프롬프트가
반복될 수 있는데, 그럴 때는 검사 간격을 늘리거나 앱 번들로 만들어 실행하면 된다.
노트북에서는 F8이 미디어 키라서 `fn`을 같이 눌러야 한다.

macOS 쪽은 CoreGraphics를 직접 호출하도록 만들어뒀지만 실제 맥에서 검증하지는 못했다.
처음에는 테스트 모드로 인식이 되는지부터 확인하는 편이 낫다.

## 설정 저장

조작할 때마다 자동으로 저장되고 다음 실행에서 그대로 복원된다. 감시 영역, 버튼 영역,
견본 이미지, 인식 기준, 학습한 클릭 보정값, 각종 옵션이 들어간다. 저장 위치만 OS마다 다르다.

- Windows: `%APPDATA%\AllowClicker\config.json`
- macOS: `~/Library/Application Support/AllowClicker/config.json`

## 인식이 안 될 때

`한 번 검사`를 누르면 왜 못 찾았는지 로그에 남는다. 지정한 색이 영역 안에 몇 퍼센트
있는지, 후보가 어떤 조건에서 걸렸는지(크기, 비율, 채움율, 글자 비율, 견본 일치도),
색을 무시한 자동 탐지로는 뭐가 보이는지까지 나온다. 기준이 꼬였으면 `기본값`으로
되돌린 뒤 버튼 영역을 다시 지정하면 된다.

## 구조

```
run.py                     실행 진입점
allowclicker/
  detector.py              버튼 탐지, 캘리브레이션, 견본 비교 (numpy만 사용)
  capture.py               화면 캡처 (mss)
  worker.py                감시 루프 (탐지 → 좌표 확인 → 클릭 → 재시도)
  config.py                설정 저장/복원
  geometry.py              좌표와 영역
  platforms/               OS별 구현 (windows.py, macos.py, base.py)
  ui/                      tkinter 화면 (app.py, overlay.py)
```
